This is the desk where streams, reviews, and late-night sessions actually happen — built around an Alienware 16 Area-51 and a curved Alienware ultrawide so the whole station stays on-brand without needing a full tower.

Why this layout

The Area-51 handles game + capture load as a desktop replacement. The 34″ ultrawide is the main canvas; the laptop’s 240 Hz panel sits beside it for chat, OBS, or reference. Cam faces the seat with the Kiyo V2 ring light ready when the stream light flips on.

How it runs day to day

Gaming and recording stay on the Area-51’s discrete GPU. The ultrawide carries the main game or edit timeline; the laptop screen keeps chat, Discord, and stream controls visible without overlay clutter. When it’s time to go live, the Kiyo V2 is already in the USB chain — no hunting for a spare port mid-warmup.
